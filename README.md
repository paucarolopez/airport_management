# ✈️ Airport Gate Management Tool - Version 2

## Project Description
This version focuses on the **Flight Management module**. We have introduced the ability to process arrival logs, calculate flight distances using spherical trigonometry, and generate flight path visualizations.

---

## Version 2 Features
* Load flight arrivals from text logs
* Haversine distance calculation for long-haul flights
* Analytics:
  * Flights per hour distribution
  * Flights per airline visualization
  * Schengen vs. Non-Schengen traffic classification
* Flight path visualization (KML exports for Google Earth)

---

## Project Structure
* `airport.py` → Infrastructure and coordinate logic
* `aircraft.py` → Aircraft class and flight processing logic
* `Interface.py` → GUI integration
